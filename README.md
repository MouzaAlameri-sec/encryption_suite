<h2>✨ What I Learned</h2>
<ul>
  <li><strong>ChaCha20</strong>: A fast symmetric encryption algorithm, great for mobile devices due to its speed and security.</li>
  <li><strong>SHA-256</strong>: A cryptographic hash function that securely fingerprints a message. Any small change to the input drastically changes the output.</li>
  <li><strong>PBKDF2HMAC</strong>: This turns a password into a strong encryption key. It adds randomness (salt) and stretches it to protect against brute-force attacks.</li>
  <li><strong>RSA</strong>: An asymmetric encryption algorithm using a public-private key pair, ideal for securely sharing encryption keys.</li>
</ul>

<p>
  Together, these components helped me understand how to securely encrypt a message, derive keys, and apply cryptographic best practices.
</p>
